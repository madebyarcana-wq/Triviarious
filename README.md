# Triviarious — TikTok向け 縦型動画 & 台本 生成ツール

お題を入力するだけで、**TikTokに投稿できる縦型動画(1080×1920)** と **収録用の台本(Markdown)** を1本ずつ出力します。台本はClaude(claude-opus-4-8)がWeb検索で事実確認をしながら作成し、**参照した資料・出典**と**動画に合うBGMの提案**を台本の最下部に載せます。BGMと声入れはご自身で行う前提の構成です。

字幕・テロップのデザインは**5種類のテーマ**から選べます。

---

## できること

- 🎬 **動画**: お題に基づく縦型ショート動画(1080×1920)を1本出力
- 📝 **台本**: シーン構成表・ナレーション全文・出典・BGM提案を含む `台本.md` を出力
- 🎨 **テロップデザイン5種**: 好みのテーマを候補から選択
- 🔎 **正確性重視**: Web検索で裏付けを取り、断定を避け、出典を必ず記録
- 🎵 **BGM提案**: 雰囲気・ジャンル・テンポと、フリーBGMサイトでの検索キーワードを提示

## テロップテーマ

| テーマ名 | 雰囲気 | 向いているジャンル |
|----------|--------|--------------------|
| `pop`    | 白文字+黒縁取り、強調は黄色 | エンタメ・雑学・驚き系 |
| `news`   | 白カード+紺文字+赤アクセント | 情報・ビジネス・時事系 |
| `cinema` | 暗背景+明朝体+金アクセント | 歴史・教養・ストーリー系 |
| `neon`   | 黒背景+発光文字 | テック・ガジェット・ミステリー系 |
| `marker` | 白背景+黒太字+蛍光ペン強調 | ハウツー・学習・ライフハック系 |

プレビュー画像は `samples/preview_*.png` にあります。`python -m triviarious themes` で自分のテキストでのプレビューも生成できます。

> `cinema` は明朝体を使うデザインです。日本語の明朝フォント(Noto Serif JP、ヒラギノ明朝、游明朝、IPA明朝 など)が入っていない環境ではゴシック体で表示されます。より雰囲気を出すには明朝フォントの導入を推奨します。

## セットアップ

必要なもの:

1. **Python 3.10+**
2. **Chrome または Chromium**(テロップ描画に使用)
3. **ffmpeg**(動画のエンコードに使用)
4. **Anthropic APIキー**(台本生成のみ。動画レンダリングだけなら不要)

```bash
# 台本生成に必要なパッケージ
pip install -r requirements.txt

# APIキー(いずれか)
export ANTHROPIC_API_KEY="sk-ant-..."
#   もしくは `ant auth login` でログイン済みのプロファイルでも動作します
```

ブラウザ・ffmpegが標準の場所に無い場合は環境変数で指定できます:

```bash
export TTV_BROWSER=/path/to/chrome
export TTV_FFMPEG=/path/to/ffmpeg
```

まず環境を診断:

```bash
python -m triviarious doctor
```

> **出力形式について**: H.264対応のffmpegがあれば `.mp4`、無い場合は自動で `.webm` を出力します(TikTokはどちらも投稿可能)。mp4推奨なら公式のフルビルド版ffmpegを導入してください。

## 使い方(Web UI — おすすめ)

ブラウザ上で **検索バーにお題を入力 → テーマにカーソルを合わせて選ぶ → 色をピッカーで調整(プレビュー即反映)→ ボタンで台本＋動画を生成** まで完結します。

```bash
python -m triviarious serve
# → ブラウザが自動で開きます(http://127.0.0.1:8765)
```

画面の流れ:

1. **お題を入力**（例:「縹色」）。雰囲気・想定尺も選べます。
2. **テロップのデザインを選ぶ**。5テーマのカードにカーソルを合わせるとプレビューが切り替わり、クリックで決定。
3. **色を調整**。テーマごとに背景・強調・本文などのカラーピッカーが出ます。動かすと右側の縦型プレビューに即反映（例: 縹色 `#2792c3` に合わせる）。冒頭/本編/締めのタブで各シーンの見え方を確認できます。
4. **「お題から台本＋動画を作る」** を押すと、台本(Claude＋Web検索)→動画レンダリングまで自動実行し、その場で動画を再生。`台本.md` と動画のダウンロードリンクも表示されます。

> 台本生成をスキップして**デザインと色だけ先に確認**したい場合は「文言サンプルで動画だけ試す」ボタンでAPIキー無しでもレンダリングできます。
> 生成物は下記CLIと同じく `output/<日時>_<タイトル>/` に保存されます。

## 使い方(コマンドライン)

### 1. テロップデザインを選ぶ

```bash
python -m triviarious themes
# → output/themes/index.html をブラウザで開いて5テーマを見比べる
python -m triviarious themes --list          # 名前だけ一覧表示
```

### 2. お題から一気に作る(台本+動画)

```bash
python -m triviarious create "タコの意外な生態" --theme pop
```

`output/日時_タイトル/` に以下が出力されます:

- `script.json` … 台本データ
- `台本.md` … 人が読む台本(**最下部に出典・ファクトチェックメモ・BGM提案**)
- `video.mp4`(または `.webm`)… 縦型動画

### 3. 台本と動画を分けて作る(推奨)

台本を先に作り、内容と出典を確認・編集してから動画化する流れです:

```bash
# 台本だけ生成
python -m triviarious generate "タコの意外な生態" --style 雑学 --length 45 -o output/tako

# 台本.md を確認・修正したうえで動画化
python -m triviarious render output/tako/script.json --theme neon
```

### 4. サンプルで動画レンダリングだけ試す(APIキー不要)

```bash
python -m triviarious render samples/sample_script.json --theme pop -o out/video.mp4
```

## 主なオプション

**台本生成(generate / create)**

| オプション | 説明 | 既定 |
|-----------|------|------|
| `--style` | 雰囲気(雑学 / 解説 / ハウツー 等) | 雑学 |
| `--length` | 想定尺(秒) | 45 |
| `--model` | 使用モデル | claude-opus-4-8 |
| `--max-searches` | Web検索の最大回数 | 8 |
| `-o, --out` | 出力ディレクトリ | output/日時_タイトル |

**動画レンダリング(render / create)**

| オプション | 説明 | 既定 |
|-----------|------|------|
| `--theme` | テロップテーマ(pop/news/cinema/neon/marker) | pop |
| `--fps` | フレームレート | 30 |
| `--quality` | `draft`(静止・高速)/ `normal`(標準)/ `high`(アニメ滑らか) | normal |
| `--keep-frames` | 中間フレーム画像を残す | off |

## シーンごとの背景

台本の各シーンに `background` を書くと、そのシーンだけ背景が変わります。台本の自動生成では、話している言葉や状況に合う絵と色をClaudeが選びます。

```json
"background": {
  "motif": "poison",
  "colors": { "bg": "#160409", "accent": "#ff3b3b" },
  "image": null
}
```

- `motif`:背景に薄く描く線画。`box`(箱)・`catbox`(箱の中の猫)・`cat`・`atom`(原子)・`poison`(毒)・`flask`・`superposition`(重なり)・`document`(論文)・`book`・`question`・`lightbulb`(答え)・`light`・`wave`・`comment`・`clock`・`globe`・`magnifier`・`eye`・`heart`・`leaf`・`coin`・`chart`・`star`・`palette`
- `colors`:そのシーンだけの背景色(`bg`)と強調色(`accent`)。省略や `null` はテーマの色のまま
- `image`:自分で用意した写真やイラストのパス(台本ファイルからの相対パス可)。指定すると線画の代わりに画像を敷き、文字が読めるよう暗く(明るいテーマでは明るく)重ねます

例:[`samples/schrodinger_script.json`](samples/schrodinger_script.json)

## 台本(`台本.md`)の中身

- **構成表**: 各シーンの時間・区分(フック/本編/CTA)・テロップ・ナレーション・演出メモ
- **ナレーション全文**: 声入れ用にそのまま読める原稿
- **ハッシュタグ案 / 投稿のヒント**
- **参考資料・出典**: すべての事実主張に対応するURL・発行元・参照日
- **ファクトチェックメモ**: 諸説ある点・不確実な点の注記
- **BGM提案**: 雰囲気・ジャンル・テンポ・理由・検索キーワード(2〜3案)

サンプル: [`samples/台本.md`](samples/台本.md)

## 仕組み

```
お題 ──▶ Claude (claude-opus-4-8 + Web検索) ──▶ 台本JSON ──┬─▶ 台本.md
                                                          │
        テーマCSS + HTMLテンプレート ◀──────────────────────┘
                    │
        Chromium で各シーンを 1080×1920 に描画(入場アニメを時刻指定でサンプリング)
                    │
        ffmpeg で連番画像 → 動画(H.264/mp4 または VP8-9/webm)
```

- テロップの見た目(縁取り・グラデ・発光・フェード等)はすべて **HTML/CSS** で表現し、Chromiumでスクリーンショットします。フォントインストールやImageMagick等は不要です。
- ffmpegは「連番静止画→動画」のエンコーダとしてのみ使うため、最小構成のビルドでも動作します。
- 色調整は各テーマCSSの `var(--ov-bg / --ov-accent / --ov-text ...)` を上書きする仕組みで、**Web UIのプレビュー(ブラウザ内CSS)と実際のレンダリング(Chromium)で同じ色**が出ます。テーマの追加・微調整は `triviarious/themes/*.css` を編集します。

### 正確性への配慮

- すべての事実主張はWeb検索で信頼できる情報源を確認してから採用する方針をシステムプロンプトで指示
- 裏付けの取れない主張は使わない/誇張しない
- 医療・健康・金融・法律の断定的助言はしない
- **投稿前に必ず `台本.md` の出典に目を通してください**(最終確認は人が行う前提です)
